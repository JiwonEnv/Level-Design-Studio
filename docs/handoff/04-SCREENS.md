# 04. 화면 참고 자료

`mockups/` 이미지는 기획 중에 만든 화면 시안이다. **배치·구성·정보 항목을 참고하는 자료이고, 색·장식·그림은 따르지 않아도 된다.** 기능 규칙이 이 문서와 [01-PRODUCT-SPEC.md](01-PRODUCT-SPEC.md)가 다르면 01을 따른다.

공통 틀: 상단에 프로젝트 이름·저장 상태·Undo/Redo·미리보기·내보내기, 그 아래 STEP 1–4 단계 표시, 왼쪽 도구·라이브러리, 가운데 작업 화면, 오른쪽 속성 패널, 하단 상태줄.

---

### 06 전체 작업 흐름
![](mockups/06-workflow-overview.png)
입력 → 설계 → 생성 → 검토 → 출력의 5단계 흐름도.

### 01 STEP 1 — Map Workspace
![](mockups/01-step1-map-workspace.png)
- 지도 레이어와 참조 소스 목록, 작업 영역 사각형(면적·둘레 표시)
- 지도 소스 OpenStreetMap, 축척 표시, 기준점 정렬
- 선택한 영역을 캡처해 Image Workspace로 보낸다

### 02 STEP 1 — Image Workspace
![](mockups/02-step1-image-workspace.png)
- 왼쪽: 프로젝트 / 레이어 / 히스토리 패널
- 가운데: 이미지와 원근 보정 가이드
- 축척 표시(예: 1 px = 0.52 m), 기준점 설정

### 03 STEP 2 — 2D 설계
![](mockups/03-step2-2d-planner.png)
- 도구: 도로 그리기, 폴리곤, 건물 배치, 구역
- 속성 패널 예: Road_001 — 폭 8.0m, 곡률 반경 15m, 재질, X/Y 좌표
- 2D/3D 전환 토글

### 04 STEP 2 — 지형·도로·건물
![](mockups/04-step2-terrain-road-building.png)
- 지형 경계 처리 선택: 절벽 / 자연 연결 / 플랫폼
- 도구: 도로, 건물, 광장, 강, 계단, 옹벽
- 경고 패널, 적용된 지형 변형(Modifier) 목록, "Blender로 내보내기"

### 05 지형 편집과 부분 재생성
![](mockups/05-step2-dependency-regeneration.png)
- 지형 브러시(반경·높이), 의존 관계 그래프(지형 → 도로·건물·다리)
- 재생성 옵션: 자동 / 확인 후 / 수동, 사용자 수정 보호, 변경 전·후 비교

### 07 모듈 조립 개념
![](mockups/07-module-assembly-concept.png)
모듈 라이브러리 → 외곽선 편집 → 자동 조립 → 건축 양식 → 모듈 보정 → Blender 연동 → 결과.

### 08 벽 길이와 모듈 예시
![](mockups/08-module-length-example.png)
8m 벽 = 2m 모듈 4개, 두 번째 칸을 창문 모듈로 교체. 남는 길이는 01 명세 7.3의 순서로 처리한다.

### 09 건물 조립
![](mockups/09-building-assembly.png)
- 생성 방식 선택: 완성 건물 / 모듈 조립 / 스타일 변형
- 세부 조정 토글, "건물 재생성"
- 조립 단계 표시: 외곽선 분석 → 모듈 배치 → 개구부 → 지붕 → 검증

### 10 STEP 4 — 3D 편집과 출력
![](mockups/10-step4-3d-edit-export.png)
- 왼쪽: 스타일별 Asset Library(중세 목조, 고딕 석조, 일본 전통, 현대 건축), 모듈 카테고리, 프로젝트 구조 트리(Terrain / Roads / Buildings / Structures, 표시·잠금)
- 가운데: 3D 뷰와 Gizmo, 미니맵
- 오른쪽 건물 속성: 건물 모드(모듈 조립형), 외곽선 제어점 편집, 층수, 건물 크기, 모듈 규칙 정보(적용 스타일·모듈 규격·조립 방식·지붕 타입), 업데이트 정책(자동/수동/잠금)
- 하단 탭: 건축 스타일 프리셋 / 모듈 규칙 검사 / 변경 이력, 건물 조립 미리보기, 선택한 모듈 상세(모듈 ID, 카테고리, 크기, 피벗, 연결점)

### 11 구조물 연결
![](mockups/11-structure-connection.png)
- 구조물 탭: 건물 / 경로형 / 복합 구조물
- 연결 분석 결과 알림, 연결 정보(예: 석조 다리 폭 6m, 높이차 +1.2m), 연결 상태 목록(도로↔다리 등)

### 12 에셋 라이브러리와 에셋 상세
![](mockups/12-asset-detail.png)
- 공용 라이브러리 ↔ 프로젝트별 사용 목록(파일 복제 없음)
- 에셋 상세: 3D 미리보기(회전·확대·와이어프레임), 텍스처 맵(Base Color / Normal / Roughness / AO), 출처, 사용 중인 프로젝트 수, [파일 다운로드] [사용 위치 추적]
- **주의**: 이미지 안의 "Model v1.2 / Texture Set v2.0" 같은 버전 표시는 따르지 않는다. 에셋은 버전 번호 없이 하나의 항목으로 보이고, 프로젝트별 고정 상태만 표시한다(01 명세 9.2).
