# Level Design Studio

레퍼런스(지도·캡처·손그림)에서 시작해 지형·도로·구조물을 설계하고, 연결 규칙으로 옹벽·계단·다리를 만들어 Blender와 Unreal·Unity에서 바로 이어 작업할 수 있는 구조화된 블록아웃을 만드는 Windows 레벨 디자인 도구입니다.

## 작업 상태: 잠시 쉬어 가는 중

꼭 만들고 싶은 도구지만, 직접 붙잡아 보니 생각보다 훨씬 어려운 작업이고 시간도 오래 걸릴 것 같습니다. 그래서 개발은 잠시 멈추고, 다른 배경 작업을 하면서 필요한 부분을 천천히 고쳐 나가려고 합니다.

지금은 자료 준비와 2D 설계, 지형 높이 편집, 에셋 라이브러리의 기본 틀까지 만들어져 있습니다. 앞으로 할 일과 순서는 [개발 단계 문서](docs/handoff/05-MILESTONES.md)에 정리해 두었습니다.
